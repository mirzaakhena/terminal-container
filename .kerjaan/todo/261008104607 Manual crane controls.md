## Background
Once the crane exists, a person needs a way to drive it by hand, to try
moves and to check the crane behaves correctly. Real crane operators work
each movement separately with joysticks.

## Request
On-screen controls and keyboard keys that move the crane's gantry, trolley
and hoist, change spreader length, and lock or release a container, with a
small readout showing where the crane is.

## Done when
- [ ] On-screen buttons move the gantry, trolley and hoist, each in both directions, while held down
- [ ] The same movements work from the keyboard, and the keys are listed on screen
- [ ] Buttons switch the spreader between 20ft and 40ft and lock or release a container
- [ ] A readout shows the crane's position on each axis in metres and whether a container is locked
- [ ] Using the controls, a person can pick a container from the block and place it on a parked truck without any code changes
- [ ] Controls that cannot be used at the moment (for example, release while carrying nothing) are shown as unavailable
